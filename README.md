Crime Data Analysis & Interactive Dashboard | Power BI
📌 Project Overview
This project focuses on analyzing crime data from 2001 to 2012 using Microsoft Power BI. The objective was to transform a large and detailed crime dataset into an interactive analytical dashboard that helps identify crime trends, patterns, distributions, and variations across different years, crime categories, and locations.
The project demonstrates an end-to-end data analytics workflow — from raw dataset preparation and data cleaning to data modeling, DAX calculations, visualization, and insight generation.
The dashboard was designed with a focus on making complex crime data easier to explore and interpret through interactive visualizations and key performance indicators.

🎯 Business Objective

The primary objective of this analysis is to understand how crime patterns changed over the period 2001–2012 and provide a clear visual representation of the underlying trends.

The analysis focuses on questions such as:

How did the overall number of reported crimes change over the years?
Which crime categories contributed the most to the overall crime volume?
Which locations experienced higher crime activity?
How are crimes distributed across different categories and periods?
Are there noticeable increases or decreases in specific crime types?
What patterns can be identified from the historical crime data?

🔄 Data Analytics Workflow

The project followed a structured analytics workflow:

Raw Dataset → Data Cleaning → Data Transformation → Data Modeling → DAX Calculations → Dashboard Development → Insights

1. Data Collection

The crime dataset was obtained from Kaggle and imported into Power BI for analysis.

2. Data Cleaning & Transformation

Power Query was used to prepare the raw data for analysis. The preparation process included:

Reviewing data types and column structures
Handling missing or inconsistent values
Removing unnecessary fields where applicable
Standardizing data formats
Transforming date/time-related fields
Creating analysis-ready columns
Validating the transformed dataset
3. Data Modeling

The prepared dataset was structured within Power BI to support efficient filtering, aggregation, and visualization.

The data model was designed to allow users to analyze crime records across different dimensions such as:

Year
Crime category/type
Location
Time period
Other relevant attributes available in the dataset
4. DAX & Analytical Measures

DAX was used to create calculated measures and KPIs required for the dashboard.

Examples include:

Total Crime Records
Year-wise Crime Count
Crime Category Distribution
Percentage Contribution
Year-over-Year comparisons
Average crime metrics
Other analytical measures used within the report

These calculations helped convert raw records into meaningful metrics for decision-oriented analysis.
